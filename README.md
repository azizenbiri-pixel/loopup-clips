# LoopUp Vibes

Crée une application web mobile-first appelée LoopUp de vidéo courte type TikTok. L'écran principal doit afficher une vidéo en plein écran qui tourne en boucle. On doit pouvoir passer à la vidéo suivante en balayant vers le haut (scroll vertical). Sur le côté droit, ajoute : la photo de profil du créateur, un bouton 'Like' avec compteur, et un bouton 'Commentaires'. Ajoute une barre de navigation fixe en bas avec 3 icônes :Accueil ,Créer (+),et Profile .
